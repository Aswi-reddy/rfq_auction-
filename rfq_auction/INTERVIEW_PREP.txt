1. VALIDATE

2. GET CURRENT STATE

All this happens in ONE @transaction.atomic block. If ANY step fails,

Q: "How do you handle concurrent bids?"

- Supplier A's transaction starts first

- Supplier B's transaction:

  - Creates their bid
  - Checks against current L1
  - Correctly decides if they're L1 or extension triggers
  
Database ACID properties guarantee consistency."

Q: "How do rankings work? Isn't it O(n²)?"

A: "Good catch! My solution:

NAIVE APPROACH (O(n²)):
```python
for each supplier:
    for each bid by supplier:
        compare price
```

MY APPROACH (O(n)):
```python
bids = auction.bids.order_by('supplier_id', '-timestamp')
latest_bids = {}
for bid in bids:
    if bid.supplier_id not in latest_bids:
        latest_bids[bid.supplier_id] = bid  # Get latest only ONCE per supplier

sorted_bids = sorted(latest_bids.values(), key=lambda b: b.effective_price())
return rankings_from(sorted_bids)
```

Why it's efficient:
- Get latest bid per supplier in ONE pass (O(n))
- Sort n suppliers (O(n log n), fast)
- Total: O(n log n) instead of O(n²)

This matters with 1000s of bids per auction."

Q: "What about the extension logic? How do the 3 trigger types work?"

A: "Config defines trigger_type:
1. BID_RECEIVED: Extend if ANY bid in last X minutes
2. RANK_CHANGE: Extend if ANY supplier rank changes  
3. L1_RANK_CHANGE: Extend only if L1 supplier changes

In ExtensionService.should_extend_auction():

```python
if trigger_type == 'BID_RECEIVED':
    return True  # Always extend if in window
    
elif trigger_type == 'RANK_CHANGE':
    if ANY_rank_changed:
        return True
        
elif trigger_type == 'L1_RANK_CHANGE':
    if L1_changed:  # Detected from did_l1_change()
        return True
```

The clever part: All checked in ONE method that returns (should_extend, reason).
Makes it easy to add new trigger types - just add an elif."

Q: "How do you prevent extending past the forced close time?"

A: "Check before extending:

```python
def can_extend(self):
    close_time = self.get_current_close_time()
    proposed_close = close_time + timedelta(minutes=self.config.extension_duration)
    return proposed_close <= self.forced_close_time
```

And when extending:

```python
def extend_auction(self):
    new_time = close_time + extension_duration()
    if new_time > forced_close_time:
        new_time = forced_close_time  # Cap at maximum
    self.current_close_time = new_time
```

Also database constraint prevents invalid states:
```sql
CHECK (forced_close_time > bid_close_time)
```"
